# Scalable Authentication API

A production-style authentication API built with Node.js and Express.

## Features
- User registration
- Password hashing with bcrypt
- JWT authentication
- Protected routes
- Modular architecture

## Tech Stack
- Node.js
- Express
- MongoDB
- JWT
- bcrypt

## API Endpoints
POST /api/register
POST /api/login
GET /api/profile (Protected)

## Architecture
Routes → Controllers → Models → Middleware
